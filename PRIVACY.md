# Privacy policy

Codex Navo is a local Windows desktop application. The Codex Navo project does not operate a telemetry, analytics, advertising, account, or cloud-storage service, and the application does not send personal information to the project maintainer.

## Local data

Account authorization data, browser profiles, API keys, usage records, session indexes, application settings, proxy configurations, and notification settings are stored locally on the user's computer. Users are responsible for protecting their Windows account and local application data.

## User-requested network communication

Codex Navo communicates with networked systems only to perform features explicitly configured or requested by the user, including:

- OpenAI and ChatGPT services for login, Codex tasks, model access, quota checks, and official Codex updates;
- GitHub for Codex Navo release checks and user-requested project operations;
- proxy servers and subscription URLs entered or imported by the user;
- notification endpoints configured by the user, such as Feishu, DingTalk, Telegram, or other supported webhooks;
- websites accessed as part of a user-requested Codex task.

When a proxy is selected, applicable task traffic is sent through that proxy. Proxy operators and configured third-party services may process network metadata or content according to their own privacy policies. Codex Navo does not control those services.

## User control

Users can disable proxy routes, notification channels, update checks initiated from the application, API service access, and other optional integrations. Uninstalling Codex Navo does not automatically delete user data unless the user explicitly chooses or performs data removal.

## Contact

Privacy questions and security reports may be submitted through the [Codex Navo GitHub repository](https://github.com/1080ssf/codex-navo/issues).
