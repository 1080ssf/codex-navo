# Codex Navo v1.2.90

本版本修复 API 用量跨天显示和新账号网页会话未登录两个问题。

## API 用量按日期正确归零

- Navo API Key 用量改为按本机日期保存独立日桶。
- “今日、昨日、7 天、30 天”会和本机用量使用相同的日期范围，不再把历史累计值标记成今日用量。
- 请求上限和 Token 上限仍按完整生命周期累计，不受日期筛选影响。
- 升级时会把旧版累计数据迁移到最后一次使用日期，保留现有统计。

## 新账号同时保留网页登录

- 添加账号时同时打开官方 Codex OAuth 与 ChatGPT 登录页面，并继续使用该账号的独立 Chrome 目录。
- Codex OAuth 完成后，Navo 会继续检测 ChatGPT 网页会话；网页 Cookie 和 Codex 凭证均验证成功后才结束添加流程。
- 界面会明确提示“Codex 授权已完成，请继续登录 ChatGPT 网页端”。
- 对于旧版中尚未建立网页会话的账号，点击“网页端”会直接进入 ChatGPT 登录页，登录完成后由独立 Chrome 持久保存。
