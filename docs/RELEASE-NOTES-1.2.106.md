# Codex Navo v1.2.106

## Compact routes and clearer proxy names

- Standalone proxy nodes now display the route name entered by the user, such as `美国VPS`, instead of repeating an IP address on account and API Key cards.
- Airport subscriptions retain their individual node names so users can still distinguish and switch exits precisely.
- The account route picker now groups routes by source. Airport subscription groups are collapsed by default and expand independently.
- Single-node network panels use a shorter header, column header, node row, and action row, removing the remaining vertical whitespace.
- Responsive single-column layouts no longer inherit the calculated desktop grid height.
