# Codex Navo v1.2.89

这是自仓库上一版公开代码以来的一次大型更新。Codex Navo 已从基础的多账号切换工具扩展为集账号隔离、额度监控、API 账号池、代理线路、会话管理、通知提醒和悬浮窗于一体的 Windows Codex 工作台。

## 本次更新亮点

### OpenAI 兼容 API 与账号池

- 新增本机 OpenAI 兼容 API，默认监听 `127.0.0.1:18300`。
- 支持 `/v1/models`、`/v1/responses` 和 `/v1/chat/completions`。
- 可以为不同 Navo Key 选择普通账号和临时账号，并单独设置账号顺序、模型和代理线路。
- 新建 Key 默认不选择账号，完整 Key 只显示一次，磁盘仅保存加盐哈希。
- 根据账号真实能力检测模型，避免 Free 账号显示实际不可用的模型。
- 账号额度耗尽、限流、授权错误或上游临时异常时，自动冷却当前账号并尝试账号池中的下一个账号。

### API Codex 稳定性

- API Codex 启动前会检测代理可用性，并显示代理检测、项目会话加载和 Codex 启动进度。
- 修复 Responses 请求结构导致的 HTTP 400。
- 修复账号池切换或 Codex 重连后本地 API Key 被提前恢复、继而出现 HTTP 401 的问题。
- 同时跟踪新版 `codex.exe` 与旧版 `ChatGPT.exe`，Codex 仍在运行时不会撤销临时 API 凭据。
- 运行中切换 API 代理会先验证新线路，失败时自动恢复原线路。
- API Key 的定时任务与普通账号隔离，避免切回普通账号后误触发 API Codex 已运行过的任务。

### 临时账号与第三方数据包

- “添加账号”现在统一提供登录并授权、导入已有账号、创建 API 和导入第三方数据包四个入口。
- 支持导入 Sub2API/toSub2、CPA/CLIProxyAPI、Cockpit、9router、AxonHub、Codex `auth.json`、Codex-Manager 和访问令牌数据包。
- 导入凭证归入可折叠的“临时账号”，只参与本机 API 反代与轮转，不创建网页环境，也不单独启动 Codex。
- 完整 OAuth 凭证支持自动续期；只有访问令牌的数据包会按令牌有效期使用。

### 网络代理与节点管理

- API 服务使用 `18300`，代理运行时使用可复用且自动避让占用的 `18301-18399` 端口池。
- 支持 HTTP、HTTPS、SOCKS5、SS、SSR、VMess、VLESS、Trojan、Hysteria、Hysteria2、TUIC 和 WireGuard。
- 支持订阅链接、Base64 订阅、Clash 配置、单节点、多节点、描述性 SOCKS5 文本及拆分的服务器/端口/用户名/密码格式。
- 节点检测结果随完成随时显示，全部结束后按照可用状态和延迟排序。
- 账号网络弹窗新增“检测当前线路”，网络输入框焦点和单节点列表布局同步修复。

### 用量、额度与缓存

- 统一展示普通账号和 API Codex 的输入、缓存、输出、缓存命中率和 Token 估值。
- API 卡片额度进度条按照账号池总额度换算。
- 支持今天、昨天、近 7 天、近 30 天和全部时间范围。
- 优化 GPT-5.6 缓存边界和缓存写入统计，减少因统计口径造成的偏差。

### 会话管理、通知与悬浮窗

- 会话按项目分组，支持进行中、失败、全部和已归档分类，以及折叠、归档、删除与失败记录清理。
- 通知文案完全使用用户输入内容，不添加模板变量。
- 支持 Windows、飞书、钉钉和 Telegram 通知，可导入本地音频作为提示音。
- 新增可调透明度和样式的悬浮窗，展示当前账号、额度、任务进度及当前/累计 Token 用量。
- 悬浮窗支持置顶、托盘显示/隐藏和 `Ctrl+Alt+N` 快捷召回，并跟随 Navo 语言实时切换。

### 界面与本地化

- 完善中文界面，并让 Navo 与 Codex 启动语言默认跟随 Windows 设置。
- 账号列表支持卡片/列表模式、普通账号/API Codex/临时账号分类折叠。
- 优化添加账号、API Key、语言设置、会话管理、通知设置、启动选择和代理节点等界面布局。
- 应用设置新增 Codex Navo、Codex Desktop 更新卡片，以及 Telegram、QQ群和 GitHub 社区入口。

## 安装与升级

1. 下载 `Codex-Navo-Setup-1.2.89-windows-x64.exe`。
2. 建议先退出正在运行的 Codex 和 Codex Navo。
3. 运行安装包覆盖安装，已有账号、设置、项目和会话数据会保留。
4. Windows 可能因为安装包暂未签名而显示“未知发布者”。
