# Codex Navo 1.2.147

本版本集中改善 CLI 诊断、额度并发读取、更新状态、界面布局和历史优化备份保护。安装包面向 Windows x64。

## 主要更新

- **CLI 诊断**：在“应用设置 → Codex CLI 运行依赖”查看 PATH、npm、托管和桌面等来源的候选、版本校验结果与失败明细，支持重新检测和显式路径。异步检测具有缓存与独立时限，慢来源不会丢弃已找到的候选；桌面端与 CLI 的就绪状态分别判断。
- **额度与任务状态**：后台、主界面、浮窗、健康检查、唤醒和账号池刷新共用请求归属，完善并发、截止与退避处理。结果未确认的提交不自动重发；不把用户自行消耗额度视为自动唤醒成功。浮窗分别显示额度读取时间和状态快照时间，明确最近活动根任务。
- **更新状态**：分离缓存读取与主动检查，完善线路切换后的生命周期、取消与显式安装状态。安装包探测在 HEAD 返回 405/501 时支持有界 Range GET 回退，并及时取消响应正文。
- **布局与双语**：调整账号卡片断点、操作区、网络节点列表和通知声音控件；启动弹窗中间区域独立滚动，展开备份后仍能看到底部操作。浮窗按内容调整高度并提供小屏滚动，双额度条对齐，补齐动态线路、到期和启动提示的中英文文案。
- **备份保护**：历史优化接入活动文件保护、独立备份、空间预算与哈希校验，覆盖两个启动入口和恢复路由。可查看备份信息；读取失败时保留提示并允许重试。
- **账号工具与本地状态**：模型目录绑定当前目标，支持分批结果、失效任务恢复、取消与搜索分组；修复重置卡刷新后操作恢复及结果状态区分。新 Key 不再默认全选账号，旧配置显式兼容。项目归属、排序与隐藏项采用有界合并并保留异常恢复。
- **用量读取性能**：新增及历史迁移使用游标索引，减少重复全表查找；不改变统计或计价规则。2000 文件合成样本中，首次索引由 5426 ms 降至 2166 ms，迁移由 1522 ms 降至 468 ms；这些结果不代表真实账本或全流程都能获得相同比例提升。
