# Codex Navo 1.2.110

This release completes the two-language interface pass and refreshes several frequently used controls in Application Settings and expandable lists.

## Highlights

- Navo and the Codex launch dialog now offer only English and Simplified Chinese.
- Account health results, account order, request counts, and token summaries now switch fully to English.
- Expand/collapse buttons use a consistent, precisely centered chevron instead of font glyphs that shift between typefaces.
- Application Settings now includes System, Light, and Dark appearance modes. The selected mode is remembered, and System mode responds to Windows theme changes.
- The Codex update card now displays the Codex application logo instead of the temporary letter icon.

- UI locale audit
- Locale and UI regression tests
