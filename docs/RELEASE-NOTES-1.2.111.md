# Codex Navo 1.2.111

This patch focuses on visual polish and reliable dark-mode rendering.

- Compact, centered chevrons no longer expand to the full width of their parent.
- Account-network configuration now presents the selected route and grouped nodes in a clearer, scrollable layout.
- Language and appearance choices use Navo-styled menus instead of browser-native dropdown popups.
- The Codex update card embeds its logo, preventing broken-image placeholders after installation.
- Dark mode now covers the top bar, local usage area, estimate panel, dialogs, route picker, and settings menus.
